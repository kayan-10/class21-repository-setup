# Class 21 – Repository Setup and Access Control

## Project Purpose
This repository demonstrates how to create and manage a GitHub repository.

## Repository Visibility
The repository is Public, so anyone can view it.

## Collaborators and Roles
- Repository Owner: Admin
- Teammate 1: Write
- Teammate 2: Write

## Project Files
- README.md: Explains the project.
- .gitignore: Lists files that Git should ignore.

## Licence
No licence file is included. Other people can view the repository, but they do not have permission to reuse the code.

## Collaboration
Team members can contribute to the project according to their assigned roles.
